# ForgeAgent: Building a Coding Agent from Scratch
## Udemy Course Outline (Adapted for Platform Best Practices)

**Course Title:** Building a Coding Agent from Scratch in Pure Python  
**Subtitle:** Create Your Own AI Coding Assistant Without Frameworks — From Loop to Capstone  
**Agent Name:** Forge  
**Target Audience:** Intermediate Python developers who want to understand and own their own AI coding agents.

**Learning Objectives:**
- Understand that an agent is primarily a control loop + tools + state.
- Build a complete, runnable coding agent in pure Python.
- Implement memory, tool calling, planning modes, and feedback loops.
- Swap between cloud and local models.
- Use the finished agent to build a small project.
