# OBS Recording Guide for This Course

## Camera Background Removal
1. Install the free **obs-backgroundremoval** plugin.
2. Right-click Camera source → Filters → Add “Background Removal”.
3. Choose a model, set threshold ~0.5–0.6.
4. Use a solid dark color or subtle gradient as the new background for a clean professional look.

## Making Code Look “Typed” Without Typing Everything Live
- Pre-write all code in the repository (it is already runnable).
- On camera: open the empty or partial file, then paste logical blocks while narrating.
- Or: have the finished code visible and use your mouse/cursor to highlight lines as you explain them.
- Optional post-production: use a typewriter reveal effect in your editor if you want the lines to appear one by one.
- Viewers care more about clear explanation and seeing the code run than about literal keystrokes.

## Recommended Scene Layout
- Main: your camera (background removed) in bottom-right or side.
- Large area for IntelliJ or terminal.
- Switch to full-screen code when walking through longer snippets.
- Keep audio levels consistent; use a noise gate if needed.
