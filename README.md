# ForgeAgent Udemy Course Materials

Original course content for **Building a Coding Agent from Scratch in Pure Python**.

## Repository Structure
- `docs/` — Full course outline adapted for Udemy
- `scripts/` — Lecture scripts (talking-head ready)
- `code/` — Runnable starter code and package structure
- `thumbnails/` — Generated thumbnail concepts
- `obs/` — OBS Studio scene collection (import directly)
- `slides/` — Slide deck structure notes

## Quick Start (for students)
```bash
cd code
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python forge.py
pytest
```

All code is original and written specifically for this course.
