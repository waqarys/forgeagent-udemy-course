# Capstone Notes – Lecture 8.1
## Watching Forge Build a Small Project

**Suggested project for the demo:** A simple CLI word counter or a tiny Markdown to HTML converter.

**Recording flow:**
1. Start with an empty folder.
2. Give Forge a clear goal: “Create a Python script that counts words in a text file and prints the top 5 words.”
3. Switch to plan mode first (explain why).
4. Then switch to act mode and let it write the files.
5. Run the generated script on camera.
6. Show what went wrong (if anything) and how the feedback loop fixed it.

**Talking points:**
- The agent is only as good as the tools and the prompt.
- You still review the code before trusting it in production.
- This is the same loop we built from the first section — just with more tools.

Keep the demo under 12–15 minutes. Cut any long waiting periods in post if needed.
